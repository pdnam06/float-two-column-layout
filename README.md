# Float Two Column Layout

Bài thực hành tạo bố cục hai cột bằng CSS Float:

- Cột trái: `width: 60%` và `float: left`.
- Cột phải: `width: 38%` và `float: right`.
- Container dùng pseudo-element `::after` với `clear: both` để xử lý float.
- Hai cột xếp chồng trên màn hình nhỏ.

Mở `index.html` bằng trình duyệt để xem kết quả.
